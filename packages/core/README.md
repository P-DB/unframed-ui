# @unframed/core

Accessible, themeable web components built with Lit. They work in React, Vue, Angular, Svelte, Astro or plain HTML.

```bash
npm install @unframed/core @unframed/tokens
```

```js
import '@unframed/tokens/tokens.css';
import '@unframed/core/button'; // or import '@unframed/core' for everything
```

```html
<uf-button variant="primary">Save</uf-button>
```

Every form control works inside a native `<form>`: it submits, resets, validates and respects `<fieldset disabled>`.
